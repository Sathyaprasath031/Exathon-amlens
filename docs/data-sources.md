# Data sources, licences, APIs and third-party tools

## Data

| Item | Source | Licence / terms |
|---|---|---|
| Accounts, transactions, ground-truth labels | **Generated by `amlens/generate.py`** (seeded, reproducible) | Original work, MIT |

No real customer, bank, employer or proprietary data is used anywhere. No dataset needs to be downloaded.
Customer IDs (`A0000001`), counterparties (`EXT_...`) and amounts are random.

## Regulatory reference points (used only as default thresholds)

- Cash deposits above INR 50,000 in a day need a PAN (structuring band is set just under this).
- Cash transaction reports to FIU-IND are driven by an INR 10 lakh threshold (used by the baseline rule).

These are public figures and are **configurable** in the `config` table. Check current rules before using
any value outside this demo.

## APIs

None are required. The only optional external call is the Anthropic API for case summaries. It receives
only the SQL evidence rows for one synthetic account. With no key set, a built-in template is used.
